# Files

- [Applications and actions](applications-actions.md) - Window matching (UserApp, GlobalApp, IgnoredApp), per-gesture actions with commands and conditions, persisted as Actions.gsa.
- [Gestures](gestures.md) - Named multi-stroke point patterns matched by angular probability, optionally stacked, stored in Gestures.gest.
- [Plugin system](plugins.md) - IPlugin discovery from CorePlugins.dll and Plugins\\*.dll, host injection, serialization, and sequential Gestured execution.
